# Whole Song simplification

See `context/implementations/04-app-enhancements/images/whole-song-simplification.png`. There is a problem: normally, some of the transcriptions are from audio files that are not very neat. The transcription normally puts some octaves whenever they are not. It also makes some hands play prohibitive chords that span more than one octave, with lots of notes on every chord. The left hand is doing a lot of jumps because it plays continuous octave chords, so it is not easy for the left hand to be in a single position. It needs to be jumping a lot. The same for the right hand. At the same time, there are a lot of changes on the right hand, and the melody is kind of obfuscated because the main melody is on the right hand. - easy: so, for me, at an easy level, the right hand plays the main melody on the right hand, being simplified: no chords, single notes. You need to keep all the notes that you think are part of the melody.
