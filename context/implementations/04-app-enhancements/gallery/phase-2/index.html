Decoration notes: the new rule

Implementation 04, Phase 2. Only a fusa or shorter (one or two of them) just before a note at least two figures longer is a decoration note now. Any other lone short note just before a much longer note is written as a real note, two figures shorter than that note (a semicorchea before a blanca is a corchea). A run of three or more fast notes stays as it was. Each case shows a passage drawn with the old rule and with the new one, as the page draws it; the band marks the passage. Nothing else of the sheet changes.
