# Epic 13 — Composing live (nice to have)

Compose a piece passage by passage: record into an empty score, iterate on each passage in stage mode until its sheet is clean, then insert it into the composition. Almost entirely a composition of existing capabilities (recording, staged sessions, matrix ops, rendering) with a new workflow shell.

Read first: `project-features.md` "Composing live" section.

## Story 13.1 — Live composition workflow

- Task 13.1.1 compose live: empty-piece creation, record-a-passage stage mode, insert/append/overwrite placement, per-passage BPM conversion.

## Exit criteria

Manual trial: build a short two-passage arrangement from scratch, including one passage recorded slow and converted to the target tempo.
