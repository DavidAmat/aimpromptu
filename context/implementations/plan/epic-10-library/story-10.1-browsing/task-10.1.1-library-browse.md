# Task 10.1.1 — Library browsing and management

## Subtask 10.1.1.1 — Consolidated tracks

Grid/list of promoted tracks from `library/tracks/` (real artist/track names from metadata, promotion names when multiple versions). Search box hitting names, not slugs.

## Subtask 10.1.1.2 — Metadata tags

User-defined tags (genre, artist, mood, …) stored in `metadata_library_track.json`; tag chips as filters so a pianist quickly narrows what to load.

## Subtask 10.1.1.3 — Playground library section

Second list showing playground artifacts (all tracks/versions from `playground/`), with rename and metadata edition capabilities — the staging ground before promotion.

## Acceptance

Filters combine (tag + search); edits persist across restarts.
