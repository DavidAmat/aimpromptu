# Task 8.5.1 — Drag note editing (nice to have)

Editing by dragging rectangles in the roll/falling views.

## Subtask 8.5.1.1 — Drag interaction

Rectangles draggable to another key lane and/or frame. While dragging, show landing guides: dashed lines per key with rotated ES note names; the hovered lane highlights so the target key is unambiguous.

## Subtask 8.5.1.2 — Staged changes

Drops accumulate as staged changes (visual badge on modified notes); nothing touches the matrix yet. Unlimited drags before committing.

## Subtask 8.5.1.3 — Save

Save button converts staged moves into Task 2.4.2 operations (delete + add), validates, persists to the working artifact; Cancel reverts.

## Acceptance

Manual trial: drag one wrong note of a scale onto the right key, save, verify in Matrix tab and by ear.
