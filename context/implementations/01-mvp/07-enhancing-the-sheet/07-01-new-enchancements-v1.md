# Task 1: Spacings

Normally, in classical music, there are some kind of rules in the way that we use spacing or in the way that we tend to group the corcheas in a given beam.

See `context/implementations/07-enhancing-the-sheet/images/i1.png` image. This is the typical example where we have a set of cortes, and for whatever reason, the beam of cortes has been split. There is no logic now because we are already doing a similar pattern: all the nodes are at the same height or in the same part of the pentagrama. There is no big jump that justifies the separation of the beam of the corcheas.

PLus as you can see when we end the set of corcheas, we have a "blanca" note, but it is VERY VERY CLOSE to the last corchea, which makes the pianist human playing this, very difficult visually to see it. 

I know that there is a criterion for how we render all of these notes in the pentagramma in "The Sheet": it's focused on the time it takes to get from one frame to the other. As you can see here, 100 frames elapsed from f0 to f100 of the song named "Superestrella". This is the first part of the song played by the right hand. Even though we have these requirements of time, it should be possible to add some spacing. Indeed, we are already given the capability. Whenever we open the toolbox and we select some notes, we are able to open the toolbox. However, there should be some rules for whenever we pass from a given sequence of several short-time notes like corcheas, semicorcheas, fusas, etc... we need to put more spacing to the next note, especially if it is a higher duration one. So a transition from a two-hop figure (from corchea to blanca there are two hops, one from corchea to negra and one from negra to blanca). This only applies if we come from corchea, semi corchea, fusa or semi fusa, it does NOT apply if we come from a negra or a blanca. 

In general we should put for all the notes more spacing between notes as a selector (to address the OVERALL spacing), just as we did with "Space between lines" create a new one for the overall notes separation. Then apart from this default separation we can have custom separation as we already allow in the "Spacing" pill of the toolbox of Frames.
