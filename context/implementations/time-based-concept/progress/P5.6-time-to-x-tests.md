# 1. P5.6 — the one time to x map, pinned

Task: P5.6. Decisions: D-22, D-23, D-24.

## 1.1 Why this was needed

Phase 5 built the map from time to horizontal position and left three of its properties untested.
Two of them are the reason the map exists. If both staves stopped reading the same map, two notes
played together would drift apart on the page and nothing would fail; if a silence stopped
compressing, a four-second rest would push the rest of the piece off the line. Both are the sort of
fault a reader notices and a suite does not, which is what a regression check is for.

D-25, the time-fraction placement of a note with no counterpart in the other hand, is not covered
here because P5.3 was cancelled: a note with no counterpart keeps its own column under D-24.

## 1.2 What was built

`tests/time-to-x.test.ts`, four checks in two groups.

**One map for the whole system.** Two hands striking in the same column are given the same x, and a
column eight later is further along the page. The ruler's selectable region for a column starts
where that column's noteheads are, within a pixel: if the two disagreed the page would say one thing
and the reader would click another.

**Silence takes the room silence needs.** The same two notes are drawn four columns apart and a
hundred columns apart, which at 40 ms is four seconds of nothing. The long one is wider, because it
is longer, and takes well under half of what a page proportional to time would spend. The same fact
per column: a column carrying a notehead is several times the width of one carrying nothing. And
every silent column is the same sliver, so a rest reads as an even stretch rather than as a run of
uneven gaps.

## 1.3 Decisions taken inside the task

The compression check is written against what a proportional page would cost rather than against a
fixed number of pixels. A fixed number would fail the first time a notehead's width or the padding
changed, for a reason that has nothing to do with compression.

## 1.4 Things I believed that turned out false

I expected silence to be compressed to almost nothing and the far pair to be barely wider than the
near one. Measured, four seconds costs about half of what proportional spacing would, not a tenth: a
silent column is a sliver but it is not free, and ninety-six of them add up. That is the right
behaviour, because a long rest should still read as long, but the check had to be written against
the measurement rather than against what I assumed.
