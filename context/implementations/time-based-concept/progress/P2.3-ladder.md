# P2.3 — `matrix/ladder.py`, naming one peak fixes the rest

## 1. What it does

The user points at one pile of gaps and says what it is. "That 337 ms peak is the negra." Every
other figure follows by proportion, and the preview says immediately what each other peak becomes,
so the choice can be judged before it is saved.

## 3. Decisions taken inside the task

**`nearest_figure` lives here, and P3.2 must import it.** The plan puts proportional figure
selection in P3.2's `notation/figures.py`, but P2.3 needs the same comparison for the preview.
Writing it twice is exactly the class of bug this refactor removes, so it is written once, here, and
the module docstring tells P3.2 to import it. If P3.2 prefers to own it, it should move it and leave
an import behind, never copy it.

**A shift is a re-pointing, not a recalculation.** `shift_ladder(ladder, 1)` keeps every millisecond
value and moves the name: `negra = 300 ms` becomes `dottedNegra = 300 ms`. A shift that would leave
the nine-figure vocabulary raises rather than clamping, because silently refusing to move is worse
than saying so.

**The dotted figures take part in the shift order.** The ladder is sorted by length, so one step up
from a negra is a dotted negra, not a blanca. That is the finer control the user wants when a
passage reads slightly too short.

**`header_label` is here rather than in the passage module.** It is a pure rendering of a ladder,
and P3.4 needs it for every passage it creates.

## 4. Things I believed that turned out false

I expected the fit error to be a percentage. The contract defines it as `abs(log2(gap / figure))`,
which is the same number the comparison minimises, so the two can never disagree. `FigureFit`
carries a `percent_off` property for the UI, derived from the log value rather than measured
separately.

## 5. Tests

Nine ladder tests, all passing. The two that matter most:

- **The 120 ms case.** With the negra at 320 ms, 120 is exactly 40 ms from both 160 and 80. The test
  asserts the two absolute distances are equal and that the answer is still a corchea, every time.
- **The swung pair.** With the negra at 337 ms, both 211 and 125 resolve to a corchea, which is what
  the printed sheet shows and the reason the dotted corchea is banned.

Plus, on the real recording: naming the dominant peak a negra labels 125 and 212 as corcheas, 337 as
a negra, 674 as a blanca, and prints `negra = 337 ms · ≈178 BPM`.
